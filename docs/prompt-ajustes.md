# Ajustes atuais: aplicação local e simples

Este documento substitui o pedido anterior de integração externa. A instrução mais recente do usuário é manter o projeto sem provedor de IA em tempo de execução.

## Escopo

- Comparar vaga e currículo por regras locais.
- Mostrar compatibilidade textual, termos presentes e ausentes.
- Organizar a formatação do currículo sem criar fatos.
- Preservar edição de requisitos, exemplo fictício, aviso de resultado desatualizado, consulta ao original, edição do currículo, prévia, cópia e impressão em PDF.
- Preservar Tailwind e os controles no padrão shadcn/ui.
- Não implementar API de IA, backend, credenciais, login, banco ou histórico.
- Informar claramente que não existe reescrita semântica conforme a vaga.

## Alterações executadas

Removidos a ação de adaptação externa, seu cliente, endpoint, servidor local, testes exclusivos da integração, proxy e configuração da função de hospedagem. Atualizados os comandos e o README para execução estática, sem arquivo .env.
